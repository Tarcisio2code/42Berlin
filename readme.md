# 42 Berlin — Software Engineering

My projects and progress through the **42 Berlin Software Engineering curriculum**.

The curriculum is project-based and focused on **C, C++, Unix/Linux, systems programming, algorithms, networking, and software architecture**, with an emphasis on problem-solving and peer-to-peer learning.

## Selected Projects

* **[Transcendence](https://github.com/tghnx1/scenegraph)** — Full-stack real-time web platform developed as a team project, where I worked as **Tech Lead**.
  *Python · FastAPI · React · TypeScript · PostgreSQL · WebSockets*

* **[ft_irc](https://github.com/tsilva42/ft_irc)** — IRC server implementation developed as a team project, where I was the Major Contributor, focused on socket programming, multiplexing and the IRC protocol.
  *C++ · TCP/IP · Sockets · Networking*

* **[Inception](https://github.com/Tarcisio2code/42Berlin/tree/master/Projects/Inception)** — Containerized infrastructure project using Docker Compose, Nginx, MariaDB and WordPress.
  *Docker · Linux · Nginx · MariaDB*

* **[cub3D](https://github.com/Tarcisio2code/42Berlin/tree/master/Projects/cub3d)** — Wolfenstein 3D-inspired raycasting engine built from scratch in C, covering map parsing, rendering and real-time input handling.
  *C · MiniLibX · Raycasting · Graphics*

* **[Minishell](https://github.com/Tarcisio2code/42Berlin/tree/master/Projects/minishell)** — POSIX-like shell covering parsing, processes, pipes, redirections and signal handling.
  *C · Unix · Processes · Signals*

## 🛠️ Key Technical Skills
🧱 Foundational OOP (CPP 00 - CPP 01)
- **Encapsulation**: Designing classes with private attributes and public interfaces (Getters/Setters).

- **Memory Management**: Mastering the stack vs. heap allocation using new and delete.

- **Resource Management**: Understanding the lifecycle of objects (Constructors and Destructors).

- **References & Pointers**: Knowing when to use each to optimize memory and performance.

📐 Data Integrity & Overloading (CPP 02)
- **Ad-hoc Polymorphism**: Implementing Operator Overloading (arithmetic, comparison, and assignment).

- **Fixed-point Arithmetic**: Understanding non-floating-point representations for precision.

- **Orthodox Canonical Form**: Ensuring classes are robust by implementing Default Constructor, Copy Constructor, Copy Assignment Operator, and Destructor.

🌳 Inheritance & Hierarchy (CPP 03)
- **Class Extension**: Reusing code through public inheritance.

- **Construction Order**: Understanding how the compiler builds objects from the base class up to the derived class.

- **Member Shadowing**: Managing attribute and method visibility across the inheritance chain.

🎭 Advanced Polymorphism (CPP 04)
- **Subtype Polymorphism**: Using virtual functions to achieve dynamic dispatch and runtime behavior.

- **Deep vs. Shallow Copy**: Preventing memory corruption by manually duplicating dynamically allocated resources (e.g., the Brain component).

- **Abstract Classes (Interfaces)**: Implementing Pure Virtual Functions to define strict behavioral contracts for derived classes.

📝 Exceptions & Error Handling (CPP 05)

* **Custom Exceptions**: Creating exception classes derived from `std::exception` to represent specific error conditions.

* **Exception Safety**: Using `try`, `catch`, and `throw` to handle failures without crashing the program.

* **Class Collaboration**: Enforcing business rules through interactions between Bureaucrats and Forms.

---

🔄 Type Conversion & RTTI (CPP 06)

* **C++ Casts**: Using `static_cast`, `reinterpret_cast`, and `dynamic_cast` for explicit type conversions.

* **Serialization Concepts**: Converting pointers into raw integer values and restoring them safely.

* **Runtime Type Identification (RTTI)**: Determining an object's real type at runtime through polymorphism.

---

🧩 Generic Programming (CPP 07)

* **Function Templates**: Writing reusable algorithms that work with multiple data types.

* **Class Templates**: Creating generic containers and data structures independent of specific types.

* **Compile-Time Flexibility**: Achieving code reuse while preserving type safety and performance.

---

📦 STL Containers & Iterators (CPP 08)

* **Standard Template Library (STL)**: Working with standard containers such as vectors, lists, and deques.

* **Iterators**: Traversing and manipulating container elements through a unified interface.

* **Container Adapters**: Extending structures like `std::stack` while maintaining STL compatibility.

---

⚡ Advanced STL & Algorithms (CPP 09)

* **STL Algorithms**: Leveraging efficient standard algorithms instead of manual implementations.

* **Container Selection**: Choosing appropriate STL containers based on performance requirements.

* **Real-World Problem Solving**: Applying data structures, parsing, and algorithmic thinking to practical challenges.
